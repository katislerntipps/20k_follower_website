# 🌸 StudyTok Companion Website

Eine interaktive Lern-Website für TikTok Follower mit Pomodoro Timer, wachsendem Kirschblütenbaum, Lerntipps-Bibliothek und Gamification-Elementen.

## 🎯 Features

- **Pomodoro Timer** mit visueller Fortschrittsanzeige
- **Wachsender Kirschblütenbaum** - wächst mit jeder Lernsession
- **Lerntipps-Bibliothek** mit Filter und Generator
- **Punktesystem** zur Motivation
- **Achievements** zum Freischalten
- **Responsive Design** für Mobile & Desktop

## 🚀 Schnellstart

1. Öffne `index.html` im Browser
2. Navigiere durch die verschiedenen Seiten
3. Teste den Pomodoro Timer auf `timer.html`
4. Entdecke Lerntipps auf `tipps.html`

## 🎨 Design

- **Theme:** Kirschblüten (Pink, Mint, Lavender)
- **Zielgruppe:** Gen Z (15-24 Jahre)
- **Stil:** Modern, verspielt, gamifiziert

## 📱 Seiten

- `index.html` - Homepage/Dashboard
- `timer.html` - Pomodoro Timer mit Baum
- `tipps.html` - Lerntipps-Bibliothek
