# Hintergrundmusik

Platziere hier deine Hintergrundmusik-Datei.

## Anforderungen

- Dateiname: `background-music.mp3`
- Format: MP3
- Empfohlen: Ruhige, nicht zu aufdringliche Musik für konzentriertes Lernen

## Verwendung

Die Hintergrundmusik wird automatisch geladen, sobald ein Nutzer das "Hintergrundmusik" Item im Shop für 250 Punkte gekauft hat.

Die Musik läuft in einer Dauerschleife mit einer Lautstärke von 30% und kann über den schwebenden Button unten rechts an- und ausgeschaltet werden.
